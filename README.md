## 🌐 Deploy to Vercel via GitHub
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Sri Krishna Janmashtami Report"
   ```
2. Create a repository on GitHub (e.g. `JanmasthamiReport`) and push your code:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/JanmasthamiReport.git
   git branch -M main
   git push -u origin main
   ```
3. In [Vercel](https://vercel.com/):
   - Click **Add New > Project**
   - Import your GitHub repository `JanmasthamiReport`
   - Framework preset will automatically detect **Vite**
   - Click **Deploy**!
